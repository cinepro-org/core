# CinePro Manager App

This folder contains the Flutter source for the Windows manager app.

For the full setup, release, signing, Inno Setup, and contribution notes, read:

```text
../README.md
```

Useful development commands:

```powershell
dart pub get
flutter analyze
flutter test
flutter test test\manager_ui_smoke_test.dart
flutter run -d windows
flutter build windows
```

The Windows runner is generated by Flutter and lives in:

```text
windows/
```

Keep manager app changes focused on setup, updates, env editing, logs, health, service control, and uninstall behavior.
